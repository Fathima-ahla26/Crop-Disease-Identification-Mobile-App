# Crop Disease Identification Mobile Application

A mobile application that helps farmers and home gardeners identify possible crop diseases using a photo of an affected plant or leaf. The app provides disease information, treatment guidance, and allows users to save previous diagnoses and seek expert support when needed.

## Key Features

* 📷 Capture or upload crop images
* 🌱 Identify possible crop diseases
* 💊 View symptoms and treatment guidance
* 🌐 English and Sinhala language support
* 📋 Save and view previous diagnoses
* 👨‍🌾 Request agricultural expert support
* 📊 View disease history and reports

## Technologies Used

* **Frontend:** React Native, Expo
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **UI/UX Design:** Figma
* **API Testing:** Postman
* **Version Control:** Git & GitHub
